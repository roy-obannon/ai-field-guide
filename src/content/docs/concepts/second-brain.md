Descended from Niklas Luhmann's **Zettelkasten** and popularized as "building a second brain" by Tiago Forte.

## Principles
1. **Atomic notes**: one idea per note.
2. **Dense linking**: link wherever ideas connect.
3. **Backlinks**: every note shows what links to it.
4. **Structure emerges from links**, not from a folder hierarchy decided up front.

## The AI parallel
| Second brain | AI system |
|---|---|
| Atomic notes | Well-sized chunks ([RAG](/ai-field-guide/concepts/rag/)) |
| Links between notes | Knowledge graph edges |
| Backlinks / graph traversal | Retrieval by relationship rather than keyword |
| Index notes | [Progressive Disclosure](/ai-field-guide/concepts/progressive-disclosure/) |

Good notes for humans and good chunks for machines follow the same rules: self-contained, one idea, explicitly connected.

## How this site uses it
This guide is a hybrid. The **modules** are an ordered course, the way a book is. The **concepts** are atomic, densely linked notes, the way a second brain is. Modules link into concepts, and concepts link to each other. The design choice behind it was trading a free-roaming graph for a clear learning path.
