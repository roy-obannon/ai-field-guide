## The learning loop

1. **Explain**: the mechanism, not just the vocabulary.
2. **Teach back**: write it in your own words, then get it critiqued.
3. **Scenario drills**: design a real system and defend the choices.
4. **Debate**: argue a contested question.
5. **Sort**: mark each idea settled or contested. Contested concepts carry a badge in the sidebar.
